What's Inside

KEY FEATURES

Zero Dependencies

No jQuery, no Bootstrap, no framework. Pure HTML5, CSS3, and ES Module JavaScript.

Light & Dark Mode

Toggle persisted via localStorage. All 3 versions support both themes with thoughtful color systems.

Text Rotate Animation

Per-character spring animation with stagger. Cycles through words with smooth exit and enter.

Custom Cursor

Acid-lime dot with smooth lerp-lag ring. Blends on interactive elements.

Parallax Floating Images

5 images react to mouse position with depth layers. Smooth rAF interpolation.

Fully Responsive

Mobile-first breakpoints at 900px and 600px. Tested from 320px to 1440px+.

Accessibility

ARIA labels, semantic HTML5, keyboard navigation, screen reader support, focus styles.

Download CV Button

Direct PDF download from the About section. Replace with your own CV file.

Well Documented

21-section documentation with code examples for every component and customization option.
