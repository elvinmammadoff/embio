SCSS Compilation Guide

Bu səhifə SCSS fayllarının CSS-ə çevrilməsi üçün addım-addım təlimatdır.

📦 Step 1: Install Dependencies

Terminal açın və embio qovluğuna gedin:

cd embio npm install

✓ Bu əmr package.json faylındakı Sass compiler-i quraşdıracaq.

🎨 Step 2: Compile SCSS to CSS

Bütün versiyaları bir dəfə compile etmək üçün:

npm run compile:all

Və ya ayrı-ayrılıqda:

npm run compile:v1 # Version 1: Dark Industrial npm run compile:v2 # Version 2: Cream Minimal npm run compile:v3 # Version 3: Neon Cyberpunk

👀 Step 3: Watch Mode (Development)

SCSS fayllarını dəyişdikdə avtomatik compile etmək üçün:

npm run dev:v1

⚠️ Watch mode aktiv olduqda terminal açıq qalmalıdır.

Dayandırmaq üçün: Ctrl + C

📝 Step 4: Edit SCSS Files

İstədiyiniz SCSS faylını açıb dəyişdirin:

# Rəng dəyişdirmək üçün assets/scss/_variables.scss # V1 nav dəyişdirmək üçün assets/scss/_nav.scss # V2 hero dəyişdirmək üçün

🚀 Step 5: Use Compiled CSS

HTML fayllarınızda compiled CSS-ə link verin:

<!-- Version 1 üçün --> <link rel="stylesheet" href="assets/css/style-compiled.css"> <!-- Version 2 üçün --> <link rel="stylesheet" href="assets/css/style-v2-compiled.css"> <!-- Version 3 üçün --> <link rel="stylesheet" href="assets/css/style-v3-compiled.css">

💡 Tips

  • SCSS faylları assets/scss/ qovluğundadır
  • Compiled CSS faylları assets/css/ qovluğuna yazılır
  • Original CSS faylları toxunulmaz - style.css, style-v2.css, etc.
  • Watch mode aktiv olduqda faylları yadda saxladıqda avtomatik compile olur
  • Production üçün npm run compile:all əmri minified CSS yaradır
