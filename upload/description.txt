<h3>CSS / SCSS Architecture</h3>
<ul>
  <li>Single SCSS entry point: <code>assets/scss/style.scss</code> compiles all 3 versions</li>
  <li>Version overrides via <code>[data-version]</code> attribute selectors — no duplicate files</li>
  <li>All 3 version tokens in <code>_variables.scss</code> with <code>-v2</code> / <code>-v3</code> suffix convention</li>
  <li>Adding a new version = add tokens + one block in <code>_overrides.scss</code></li>
  <li>Production: single <code>style.min.css</code> + <code>main.min.js</code> covers all versions</li>
</ul>
