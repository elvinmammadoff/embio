<h3>Light &amp; Dark Mode</h3>
<p>
  EMBio features a smart theme system that works automatically without any configuration:
</p>
<ul>
  <li><strong>Auto by time</strong> — 07:00–18:00 local time → light mode, 18:00–07:00 → dark mode</li>
  <li><strong>Manual override</strong> — Toggle button saves preference to localStorage and persists across sessions</li>
  <li><strong>Flash-free</strong> — Inline <code>theme-init.js</code> runs synchronously before render, eliminating flash of wrong theme</li>
  <li><strong>Auto-resume</strong> — Clearing localStorage restores time-based auto switching</li>
  <li><strong>Per-minute check</strong> — Theme updates automatically if the user leaves the tab open across the threshold hour</li>
  <li><strong>Consistent brand color</strong> — V1 uses the same acid-lime (#c8ff00) in both light and dark mode. Button text turns black (#0f0f0f) in light mode for readability on the bright accent background</li>
</ul>

<h3>CSS / SCSS Architecture</h3>
<ul>
  <li>Single SCSS entry point: <code>assets/scss/style.scss</code> compiles all 3 versions</li>
  <li>Version overrides via <code>[data-version]</code> HTML attribute — no duplicate files</li>
  <li>All version tokens in <code>_variables.scss</code> with <code>-v2</code> / <code>-v3</code> suffix convention</li>
  <li>All version layout overrides in single <code>_overrides.scss</code> file, grouped by version</li>
  <li>Production: one <code>style.min.css</code> + one <code>main.min.js</code> covers all 3 versions</li>
  <li>Compile: <code>npm run compile</code> / Watch: <code>npm run watch</code></li>
</ul>
