EMBio — Frontend Developer Portfolio

Version 1.0.0  ·  HTML5 Template

Thank you for purchasing EMBio Portfolio Template. This documentation will guide you through setup, customization, and deployment of your new portfolio website.

EMBio is a dark-first, editorial-style HTML5 portfolio template built with pure HTML, CSS, and vanilla JavaScript — zero framework dependencies, zero build step required.

PropertyValue
Template NameEMBio — Frontend Developer Portfolio
Version1.0.0
AuthorElvin Mammadov
DateApril 2026
FrameworkVanilla HTML5 / CSS3 / JS (ES Modules)
ResponsiveYes — mobile first
Light/Dark ModeYes — persisted via localStorage
📋 Note: Basic HTML and CSS knowledge is required for customization. No build tools or Node.js are required to run the template.

After downloading and unzipping, you will find the following structure:

Key Features

  • Zero dependencies — No jQuery, no Bootstrap, no framework
  • Light & Dark mode — Toggle persisted via localStorage
  • Custom animated cursor — Acid-lime dot with smooth lag ring
  • Text Rotate animation — Per-character spring animation with stagger
  • Floating parallax images — Mouse-tracking depth effect on hero
  • Scroll reveal animations — Intersection Observer based, no JS library
  • Scrolling marquee strip — Infinite CSS animation
  • Skill cards with bracket corners — Expand on hover
  • Download CV button — Direct PDF download
  • Contact form UI — With loading state and success feedback
  • Fully responsive — 320px to 1440px+
  • CSS custom properties — Easy theming
  • ES Modules — Clean, maintainable JavaScript
  • SEO-ready — Semantic HTML5, meta description, ARIA labels
  • W3C valid — Clean, standard-compliant markup

4. Quick Start

⚠ Important: The template uses ES Modules (type="module"). You must serve files over HTTP — opening index.html via file:/// will not work in most browsers.

Option A — VS Code (recommended)

  1. Install the Live Server extension by Ritwick Dey
  2. Open the em-portfolio/ folder in VS Code
  3. Right-click index.html → Open with Live Server
  4. Browser opens at http://127.0.0.1:5500

Option B — Node.js

cd em-portfolio
npx serve .

Opens at http://localhost:3000

Option C — Python

cd em-portfolio
python3 -m http.server 3000

Opens at http://localhost:3000

6. Colors & Themes

All colors are defined as CSS custom properties in assets/css/variables.css. The template supports two themes controlled by the data-theme attribute on <html>.

Dark Mode (default)

:root, [data-theme="dark"] {
  --bg:      #080808;   /* main background */
  --bg-2:    #0f0f0f;   /* section alternate bg */
  --bg-3:    #161616;   /* card backgrounds */
  --text:    #e8e8e8;   /* primary text */
  --muted:   #666666;   /* secondary text */
  --faint:   #333333;   /* borders, subtle text */
  --border:  rgba(255,255,255,0.07);

  --accent:       #c8ff00;  /* primary accent (acid lime) */
  --accent-hover: #d9ff33;  /* accent on hover */
  --accent-text:  #080808;  /* text on accent backgrounds */
  --accent-label: #c8ff00;  /* labels, links */
}

Light Mode

[data-theme="light"] {
  --bg:      #f5f5f0;
  --bg-2:    #eeede8;
  --text:    #0f0f0f;
  --muted:   #555555;
  --accent:       #5a7a00;  /* dark olive — readable on light bg */
  --accent-label: #5a7a00;
  --accent-text:  #ffffff;
}

Change Accent Color

To change the entire accent color scheme, update these three values in variables.css:

/* Example: change to electric blue */
--accent:        #0070f3;
--accent-hover:  #338fff;
--accent-text:   #ffffff;

8. Hero Section

The hero features two interactive effects:

8.1 Text Rotate

Cycles through a list of words with per-character spring animation. To change the words, edit assets/js/hero.js:

const words = [
  'beautiful',
  'fast ⚡',
  'accessible',
  'creative',
  // add your own words here
];

8.2 Floating Parallax Images

5 images float and respond to mouse movement. Each has a data-depth attribute controlling parallax intensity. Edit positions and images in index.html:

<div class="fl-img" data-depth="1.4" style="top:10%;left:20%">
  <img src="assets/images/your-image.jpg" style="width:230px;height:175px;transform:rotate(-11deg)">
</div>

Higher data-depth = more movement. Recommended range: 0.4 – 2.5

8.3 Marquee Strip

Update the skill items in the marquee by editing the .marquee-track div in index.html. Duplicate all items for a seamless loop.

10. Skills Section

The skills grid displays 12 skills in a repeat(4, 1fr) grid (desktop). Each card has bracket-corner decorations and a linear SVG icon that animates on hover. Hover background color matches the version's accent color via [data-version].

<div class="skill-cell reveal">
  <span class="skill-bracket-tr" aria-hidden="true"></span>
  <span class="skill-bracket-bl" aria-hidden="true"></span>
  <div class="skill-icon-wrap">
    <svg viewBox="0 0 24 24" fill="none" stroke="ACCENT_COLOR"
         width="44" height="44" aria-hidden="true">
      <!-- Linear SVG paths here -->
    </svg>
  </div>
  <h3 class="skill-name">Skill Name</h3>
  <p class="skill-desc">Skill description...</p>
</div>

Grid layout: repeat(4, 1fr) on desktop, repeat(2, 1fr) on tablet, 1fr on mobile. Add cards in multiples of 4 for even rows.

Hover colors per version:

/* V1 */ .skill-cell:hover .skill-icon-wrap { background: rgba(200,255,0,0.1); }
/* V2 */ [data-version="2"] .skill-cell:hover .skill-icon-wrap { background: rgba(26,86,219,0.15); }
/* V3 */ [data-version="3"] .skill-cell:hover .skill-icon-wrap { background: rgba(255,0,204,0.15); }

11. Projects Section

Projects alternate left/right layout automatically via CSS nth-child(even). Add projects by copying a .project-item article block. Update number, name, description, tech tags, live URL, and image.

12. Pricing Section

Three tiers: Starter, Professional (featured), Premium. The .featured class on the middle card adds the highlight styling and "Most Popular" badge.

To update prices, find the .price-amount spans inside each .price-card and update the number. To add/remove features, edit the .price-features list items. Change .pf-no class to mark a feature as unavailable (shows ✗ instead of ✓).

13. Blog Section

3-column card grid. Each card: image with category badge, date, title, excerpt, "Read More" link. Update the href on .blog-link to point to your actual blog post pages.

14. Contact Section

The contact form is purely front-end (UI only). To make it actually send emails, integrate a service like Formspree, Web3Forms, or EmailJS.

Formspree Integration (easiest)

<!-- In index.html, update the form tag: -->
<form class="contact-form" action="https://formspree.io/f/YOUR_FORM_ID" method="POST">

Then remove the onsubmit="handleFormSubmit(event)" attribute and the inline <script> at the bottom.

15. CSS Architecture

CSS is split into 5 focused files. All 3 versions share the same files — version-specific styles use [data-version] attribute selectors.

FileContents
variables.cssCSS custom property tokens for all 3 versions — V1 (default), V2 ([data-version="2"]), V3 ([data-version="3"])
base.cssCSS reset, shared section/container styles, scroll reveal, keyframes
nav.cssNavigation bar, theme switch, mobile burger menu
sections.cssAll section styles (hero, about, skills, projects, pricing, blog, contact, footer) + V2 & V3 layout overrides at the bottom
responsive.cssMobile breakpoints (900px and 600px)

How Version Overrides Work

Each HTML file declares its version via data-version on the <html> tag:

<!-- index.html -->  <html data-version="1">
<!-- v2.html -->     <html data-version="2">
<!-- v3.html -->     <html data-version="3">

Version-specific CSS uses attribute selectors in variables.css (tokens) and sections.css (layout):

/* variables.css — color tokens per version */
[data-version="2"] { --accent: #1a56db; --bg: #fafaf8; }
[data-version="3"] { --accent: #ff00cc; --bg: #050508; }

/* sections.css — layout overrides */
[data-version="2"] .hero-headline { font-size: clamp(3rem, 10vw, 8rem); text-align: center; }
[data-version="3"] .section-title { text-shadow: 0 0 60px rgba(255,0,204,0.15); }

Centering Content

All section content is wrapped in .section-inner which provides the max-width container:

.section-inner {
  max-width: 1100px;
  margin: 0 auto;
  width: 100%;
}

15b. SCSS Architecture

SCSS source files compile to a single style.min.css covering all 3 versions. No v1/ subfolder — all files live directly in assets/scss/.

Folder Structure

assets/scss/
├── style.scss           ← 🎯 Entry point (@use all partials)
├── _variables.scss      ← All tokens: V1, V2 (-v2), V3 (-v3) suffixes
├── _mixins.scss         ← Shared mixins (mobile, tablet, flex-center…)
├── _base.scss
├── _nav.scss
├── _responsive.scss
├── _overrides.scss      ← ALL version overrides in one file (V2, V3, …)
├── sections/
│   ├── _hero.scss
│   ├── _about.scss
│   ├── _portfolio.scss
│   ├── _contact.scss
│   └── _footer.scss
└── components/
    ├── _cursor.scss
    ├── _floating-images.scss
    └── _text-rotate.scss

Variable Naming Convention

// V1 — no suffix (default)
$accent:          #c8ff00;
$bg:              #080808;

// V2 — -v2 suffix
$accent-v2:       #1a56db;
$bg-v2:           #fafaf8;
$bg-dark-v2:      #0d0d0f;   ← V2 dark mode variant

// V3 — -v3 suffix
$accent-v3:       #ff00cc;
$accent-2-v3:     #00e5ff;   ← Cyan secondary accent
$bg-v3:           #050508;

Compile Commands

npm install          # Install sass (one time)
npm run compile      # Compile → assets/css/style.min.css
npm run watch        # Watch mode (auto-recompile on save)
npm run dev          # Alias for watch

Adding a New Version

// 1. Add tokens to _variables.scss with -v4 suffix
$accent-v4: #your-color;

// 2. Add a new section in _overrides.scss
// (no new file needed — just append to the existing file)
[data-version="4"] { --accent: #{$accent-v4}; }
[data-version="4"] .hero-headline { /* your overrides */ }

// 3. No import change needed — style.scss already imports overrides

// 4. Add data-version="4" to your new HTML file
<html data-version="4">

Adding Custom JavaScript

Create a new .js file in assets/js/, export a function, and import it in main.js:

// assets/js/myfeature.js
export function initMyFeature() {
  // your code here
}

// assets/js/main.js — add:
import { initMyFeature } from './myfeature.js';
// inside DOMContentLoaded:
initMyFeature();

18. Performance

  • All images use loading="lazy" (except hero which uses loading="eager")
  • Animations use only transform and opacity — no layout-triggering properties
  • Google Fonts loaded with rel="preconnect" for faster DNS
  • CSS custom properties eliminate redundant values
  • ES Modules enable tree-shaking and deferred parsing
  • Use style.min.css and main.min.js in production for best Lighthouse scores

Production Switch

Replace the 5 stylesheet links and module script in <head> with:

<link rel="stylesheet" href="assets/css/style.min.css" />
<!-- ... -->
<script src="assets/js/main.min.js" defer></script>
